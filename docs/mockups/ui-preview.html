ボタン（GPIO9）

  • 短押しOLED ページ送り Status→Position→Home
  • 長押し 2s出発地点(HOME)を確定 基準点保存・seq リセット
  • ダブル任意発信 合流目印・テスト（LBT を通す）

ブザー（GPIO11）

  • ピッ送信成功
  • ピピッGPS fix 獲得
  • ププッLBT busy＝送信見送り
  • ピーッHOME 確定

青 LED（ボタン内蔵） — 消音時の視覚版

  • 遅い点滅GPS 探索中（no fix）
  • 消灯fix 確立・待機
  • 1回閃光送信成功
  • 速い2回LBT busy
  • 1秒点灯HOME 確定
App B

PaperMono 受信機

3.97" 480×800 4 階調 e-ink・タッチ／据置 or 携行

PaperMono の操作（物理ボタン ＋ タッチ）

  • ボタン A ▲グリッド拡大 UP・軌跡／帰路の両画面
  • ボタン B ▼グリッド縮小 DOWN・スケールバーが連動
  • 下部タブ画面切替 軌跡 ⇄ 帰路（タッチ）
  • 電源(赤)電源 / スリープ

方位は両機とも地磁気センサ非搭載のため North-up 固定。距離・絶対方位は現在座標と出発点から haversine / bearing で算出。送信フレームは NostosFrame 16 バイトのまま（衛星数は C6L OLED が自機 GPS を直読して表示）。仕様の一次情報は docs/UI.md。
