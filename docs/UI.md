# UI 仕様 — Nostos（C6L 送信機 ＋ PaperMono 受信機）

> 確定版。実装（C6L OLED / PaperMono e-ink）の一次仕様。モックアップは
> `docs/mockups/ui-preview.html`（Artifact 化）を参照。

## 全体像

Nostos は 2 台で 1 組。**C6L＝GPS を持って携行する送信＋自己表示端末**、
**PaperMono＝受信して大画面に軌跡・帰路を描く端末**。

- **運用モード1（据置）**: PaperMono を出発地点に設置し、携行 C6L の足取りをリアルタイム表示。
- **運用モード2（携行）**: PaperMono も持ち歩く。C6L の現在座標＋保存済み出発点から
  「出発点の方角・距離」を PaperMono の帰路画面に描く。
- どちらでも **軌跡マップは常時有効**。帰路画面は携行時に価値が出る。

### 方位の扱い（HW 制約・重要）

C6L・PaperMono とも**地磁気センサ非搭載**（PaperMono の IMU は BMI270＝6 軸／磁北なし）。
よって画面が「端末の向いた方角」を指すことはできない。方位は次で解決する:

- 表示は **North-up（上＝真北）固定グリッド**。
- 距離と**絶対方位**（例 210°/SW）は、現在座標と出発点座標から正確に算出（haversine / bearing）。
- 進行方位が要る場面は、**移動履歴から course made good（進路）を推定**して併記（磁気センサ不要）。

## アプリA：C6L 送信機（0.66" OLED ＋ ブザー ＋ ボタン）

- **画面**: 0.66" OLED（I2C SDA=10 / SCL=8、SSD1306 系と推測・**実装前に variant.h と M5 公式で解像度/コントローラ確認**）。
- **操作ボタン＝本体正面ボタン（GPIO9・BOOT ストラップ・active-low）**。ブザー＝GPIO11。
  - 側面のリセットボタンは MCU の RESET（EN/CHIP_PU）直結＝**GPIO として読めない**（再起動専用）。
     page 送り・HOME 確定・任意発信の各操作はすべて**正面ボタン**に載せる。

### OLED 3 ページ（ボタン短押しで循環）

| ページ | 表示内容 |
| --- | --- |
| **STATUS** | 衛星補足数 / fix 状態 / seq / 直近 LBT 結果（free・busy）/ 時刻 |
| **POSITION** | 現在座標（緯度・経度）/ 高度 / 衛星数 |
| **HOME（帰路）** | 出発点までの距離 / 絶対方位（度＋方位名）/ 推定進路 course |

### ボタン割当

| 操作 | 動作 |
| --- | --- |
| 短押し | OLED ページ送り（STATUS → POSITION → HOME） |
| 長押し（2s） | **出発地点（HOME）確定**（現在の GPS を基準点として保存・seq リセット） |
| ダブルクリック | **任意発信**（合流目印／テスト。LBT を通す） |

### ブザー鳴らし分け

| 音 | 意味 |
| --- | --- |
| ピッ（中1） | 送信成功 |
| ピピッ（高2） | GPS fix 獲得（no-fix→fix 遷移） |
| ププッ（低2） | LBT busy＝混雑で送信見送り |
| ピーッ（長1） | HOME 確定 |

> ハートビート送信は既定で無音（省電力・迷惑回避）。

### 青色 LED（正面ボタン内蔵）＝ブザー言語の視覚版

単色 LED なので**点滅パターン**で状態を示す（消音運用・騒音下の視覚確認に）。

| 表示 | 意味 |
| --- | --- |
| 遅い点滅（0.5Hz） | GPS 探索中（no fix） |
| 消灯 | fix 確立・待機（省電力） |
| 1 回フラッシュ | 送信成功（ブザーと同期） |
| 速い 2 回点滅 | LBT busy＝送信見送り |
| 1 秒点灯 | HOME 確定 |

> ⚠️ LED の駆動 GPIO は要確認（GPIO9 はボタン**入力**。LED は別ピンの可能性が高い）。variant.h / M5 回路図で確認。

## アプリB：PaperMono 受信機（3.97" 480×800 4 階調 e-ink・タッチ）

2 画面。下部タブ（タッチ）で切替。RGB LED で新規受信（緑点滅）・低電池（赤）を即時通知。

### 物理ボタン

| ボタン | 動作 |
| --- | --- |
| A（UP） | グリッド**拡大**（軌跡／帰路の両画面。スケールバー連動）。設定画面ではフロントライトを**明るく** |
| B（DOWN） | グリッド**縮小**。設定画面ではフロントライトを**暗く** |
| 電源（赤） | 電源 / スリープ |

> A/B はコンテキスト依存の「上/下」操作（地図＝拡大縮小、設定＝明るさ増減）。

### RGB LED（左側面）＝色分けステータス

| 色・点灯 | 意味 |
| --- | --- |
| 緑 1 回点滅 | 新規フレーム受信 |
| 橙 遅い点滅 | 受信途絶（一定時間受信なし）＝リンク注意 |
| 赤 点滅 | 低電池 |
| 青 点灯 | 充電中 / USB 給電 |
| 消灯 | 通常待機（省電力） |

> 優先度: 赤（低電池）＞ 橙（途絶）＞ 緑（受信）＞ 青（充電）。

### フロントライト設定（設定タブ）

下部タブは **軌跡 / 帰路 / 設定** の 3 つ。設定タブに以下を置く。

- **明るさ 5 段階**（OFF / 弱 / 中 / 強 / 最大）。**A ▲ で明るく・B ▼ で暗く**。
- **自動消灯**（無操作 30 秒でフロントライト OFF）。ON/OFF。
- 通知 LED の色分け凡例（上表）も表示。

### 第1画面：軌跡マップ（Trail）

- **North-up グリッド**に、出発地点から辿った軌跡をプロット。
- 位置取得地点の**間を破線で結ぶ**。
- 各地点に**取得順の連番**を振る（1＝出発地点＝最古、以降加算）。現在地は強調（◉）。
- スケールバー（例: ─── 200 m ───）と N インジケータ。
- 下段ステータス: C6L 現在座標 / 衛星数 / 最終受信からの経過 / RSSI。

### 第2画面：帰路ナビ（Homing、携行時に有効）

- **現在地を中心**とした North-up グリッド。
- **出発地点を、その絶対方位に合わせてプロット**。
- プロット点の**下に距離を表示**（例: 1.24 km）。
- **来た道（辿った全経路）を薄墨（ライトグレー）で重ねて表示**。「直線の帰路方位（濃い破線）」と
  「実際に辿った道（薄墨）」を対比でき、正しく引き返せているかを確認できる。
- 据置運用では情報的に無意味なため、タブを淡色表示（無効化）にしてよい。

## データ面

- 送信フレーム `NostosFrame` は **16 バイトのまま変更しない**（PaperMono 側に衛星数は出さない方針）。
  - `version|flags|seq|lat_e7|lon_e7|time_unix|crc8`（`crates/nostos-frame` / `firmware/c6l-beacon/include/nostos_frame.h`）。
- 衛星数・高度・進路は **C6L の OLED が自機 GPS を直読**して表示（フレーム非依存）。
- PaperMono の距離・方位は受信座標 ＋ 保存済み出発点から算出（`crates/nostos-nav`: haversine / bearing）。
